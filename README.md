结合界面字符容量、源/译文字数及占位符数量，检测界面溢出和待复核译文；不声称完成语义翻译或逐token占位符一致性校验。

新增已认证的结构化录入工作台（`/operations.html`），支持批量核算、逐条结果依据、分级复核和CSV/完整JSON导出。结果由真实后端算法计算，不是预置演示数字。所有数值精确传递，不调用外部模型。

这是**只读核算**：不写库、不审批、不自动执行财务、签署、销毁或设备控制。输入条件满足不是执行授权。[算法、输入边界与接口说明](docs/OPERATIONS-REVIEW.md)。
## 企业多语言内容，从机器草稿到人工发布

TranslatorAI 是知华科技提供的企业翻译与译审协作社区源码版，适用于产品手册、合同、运营内容和多语言网站的流程学习与技术研究。

项目由[上海如静知华信息科技有限公司](https://www.zhuatech.cn/)维护，Java 工程包为 `cn.zhuatech.translatorai`。

### 工作流

1. 解析源文档并识别语言、段落、数字和版式。
2. 匹配企业术语与翻译记忆，生成机器草稿。
3. 根据术语覆盖、模型置信度、保密级别和法律属性计算译审路线。
4. 人工完成双语校对，高风险文档交给高级译审。
5. 保存源文、译文、修订和发布审批证据。

运营端能够看到语言对产能、一次通过率、术语资源、临期任务和发布审批。

移动端展示个人任务、双语反馈、术语资源与保密/法律风险升级。

### 可运行能力

- `POST /api/ai/translation/review-plan`：生成译审分数、风险等级、译审路线、预计工时和检查清单
- 企业术语库、翻译记忆库、模型版本和文档任务台账
- Vue 3 双端界面，Spring Boot REST API，JWT 岗位权限
- MySQL + Flyway、H2 自动化测试、Docker Compose
- 社区版完全本地可测，不上传语料、不需要外部 API Key

## 输入对照与版本化快照

在既有「译文长度与占位符齐套核对」基础上，新增 `/comparison.html`：基准与候选两组数据都由当前真实算法重算，按编号展示新增、移除、逐字段变化和精确数值差，支持筛选、分页和全量导出。原核算入口可导出输入快照，对照页经后端完整校验后整体导入；失败不覆盖当前输入。

快照区分项目、字段契约及算法版本。建议较宽松不代表风险已下降，输入摘要不是签名；操作人和时间仅为响应元数据，不是持久化审计。本次未新增模型调用或业务写入，也不代表全系统生产认证。详见[输入对照操作与接口说明](docs/INPUT-COMPARISON.md)。
